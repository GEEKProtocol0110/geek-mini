# Geek Mini Security

## Current status

Geek Mini is a public Alpha. It has not completed an independent security audit.

Geek Mini has no account, wallet, or token rewards. It never asks for seed phrases or private keys. Do not include seeds, private keys, or recovery phrases in a report.

Protocol security for Geek Protocol HQ, including services this app calls, is described in the [Geek Protocol HQ security policy](https://github.com/GEEKProtocol0110/geek-protocol-hq/blob/main/SECURITY.md).

## Reporting a vulnerability

Private vulnerability reporting is enabled for this repository. Report an unpatched vulnerability through GitHub private vulnerability reporting:

https://github.com/GEEKProtocol0110/geek-mini/security/advisories/new

Do not open a public GitHub issue for an unpatched vulnerability.

Include the affected commit, what you expected, what you observed, and the smallest evidence that explains the impact. Do not access another person's data, degrade the service, or submit malware. Stop once that evidence is enough to explain the issue.
